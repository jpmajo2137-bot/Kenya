# Google Play Console — API로 끝내지 못한 앱 콘텐츠(UI) 체크리스트

스토어 등록정보(제목/설명/아이콘/피처그래픽/스크린샷 7장), 데이터 안전성 CSV, 내부 테스트 1.00(1) completed 까지는 API로 반영했습니다.  
프로덕션 승격이 `FAILED_PRECONDITION` 인 이유는 아래 **앱 콘텐츠** 폼이 비어 있기 때문입니다.

Play Console → **JHP 영어 단어 암기** (`com.jph.oxfordenglish`) → **정책** → **앱 콘텐츠**

## 1) 개인정보처리방침 (필수)

- URL: `https://jhpenglish.web.app/privacy`
- 저장

## 2) 광고 (필수)

- 앱에 광고가 포함되나요? → **예**

## 3) 광고 ID (필수)

- 광고 ID를 사용하나요? → **예**
- 목적:
  - 광고 또는 마케팅
  - 애널리틱스
  - 사기 예방, 보안, 규정 준수

## 4) 타겟 사용자층 및 콘텐츠

- 대상 연령: **13세 이상만** (아동 대상 아님)
- Families 정책 해당 없음

## 5) 앱 액세스(로그인)

- 앱의 전체/일부 기능이 제한되어 있나요? → **아니요**  
  (계정 로그인 없음)

## 6) 콘텐츠 등급(IARC)

설문 권장 답:

- 폭력/성적 콘텐츠/혐오/도박 등: **없음**
- 사용자 생성 콘텐츠: **없음**
- 위치 공유: **없음**
- 디지털 상품 판매: **없음**
- 무제한 인터넷 접근: **예** (웹뷰/사전 검색 등)
- 예상 등급: Everyone / PEGI 3

## 7) 데이터 안전성

이미 API로 제출됨 (`play-store-aso/data-safety.csv`).  
콘솔에서 **게시됨** 상태인지만 확인.

## 8) 내부 테스터

- 테스트 → 내부 테스트 → 테스터에 이메일 또는 Google 그룹 추가
- 트랙 `1.00 (1)` 은 이미 **completed**

## 9) 프로덕션

위 1~6 완료 후:

- 출시 → 프로덕션 → `1.00 (1)` 출시 생성/승격
- 출시 노트(이미 준비됨):
  - KO: 첫 출시: JHP 영어 단어 암기 (Oxford 5000)
  - EN: Initial release: JHP English Words (Oxford 5000)

## API로 이미 완료

- ko-KR / en-US 스토어 등록정보 + SEO 문구
- 아이콘 / 피처 그래픽 / 폰 스크린샷 7장
- 연락처 이메일·웹사이트
- 데이터 안전성 제출
- 내부 테스트 트랙 completed
